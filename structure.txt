🔥 Day 348 — Vehicle Service Management System
For Day 348, let's build a multi-file Python project for managing vehicle customers, service records, spare parts, bills, and service history.
📌 Features
- Add customers
- Add vehicles
- View vehicles
- Search vehicles
- Add spare parts
- Create service records
- Add multiple service items
- Calculate parts cost
- Calculate labor cost
- Calculate GST
- Generate service bill
- Update service status
- View service history
- Search service records
- Service statistics
- JSON data storage
